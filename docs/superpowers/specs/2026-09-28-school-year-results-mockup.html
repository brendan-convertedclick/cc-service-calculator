How templates stay comparable

  • One master, every school. A template is edited here once and every school's rows pick it up. There are no per-school copies to drift apart.
  • Each metric has a fixed identity. Renaming "Leads" to "Enquiries" keeps every past value attached, so 2024 still compares with 2026.
  • Metrics are retired, never deleted. A retired metric stops being asked for, but past values stay and still show when you compare.
  • A metric's type locks once it has data. A number can't quietly become text. Need a different kind of value? Add a new metric.
  • Stars choose what the grid shows. Up to two starred results appear in each cell. The first star is the one shown for compared years.
